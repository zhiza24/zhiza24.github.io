# Способ запуска и план цели: статус внедрения (2026-11-26, sw v73)

Контракт: [CAPACITY_AND_COLLABORATION_MAP.md](CAPACITY_AND_COLLABORATION_MAP.md), сценарии: [CAPACITY_AND_COLLABORATION_TEST_MATRIX.md](CAPACITY_AND_COLLABORATION_TEST_MATRIX.md), PLN из [GOAL_EXECUTION_PATTERN_MAP.md](GOAL_EXECUTION_PATTERN_MAP.md).

## Сверка с игрой
- Авторская модель способов реализации по дате рождения в игре = «Механика моей природы» (`nature.js`, `P.nature.primary`, расчет не меняется). Названий Проектор/Генератор/Манифестор/МГ/Рефлектор в коде и у игрока нет, игроку их не показываем. Имена механик (Инициатор, Наблюдатель и др.) игрок уже видит в паспорте, поэтому они допустимы в «Почему так».
- Соответствие путей включения: initiator → самостоятельный запуск; observer → запрос и признание; creator → отклик и видимое участие; researcher → короткие пробы; architect → условия и понятная структура (ближе всего к оценке среды).
- `goal-path-engine.js STYLE` уже дает формат по механике для подсказок в редакторе шагов; новый слой его не дублирует, а отвечает на вопрос «когда включаешься» и «что не тянуть одному».

## Что сделано
- `capacity-engine.js` (GCapacity): профиль запуска (выбор для цели > общий выбор игрока > механика природы), одна подсказка на шаг: начать сам(а) / найти запрос / показать кому-то / передать часть / короткая проба. Если запроса нет и шаг стоит 3 дня, подсказка «не жди, создай точку контакта». Тексты чередуются.
- Карточка «Шаг по цели» на «День» (`reactor-core.js capBlock`): строка «Формат шага» + «Почему так»; свернутый блок «Как тебе легче идти к этой цели»: «Мне проще начинать, когда…», «Что лучше не тянуть одному?», «Как поймешь, что цель сдвинулась?». Вариант «по-разному, подсказки не нужны» отключает подсказку.
- PLN в `goal-path-engine.js`: `setCriterion` (критерий успеха), `setOutcome` (статус результата по неделе: есть / ожидается / без изменений, отдельно от отметки действия), `setCapacity` (способ запуска на цель), `versions[]` в плане цели (история изменений критерия, готовности, «если помешает», способа запуска). Данные по стабильному id цели, дни не сдвигаются, старые планы не мигрируются, поля только добавляются.
- Данные: `alch_v5_profile.capacity` и `tracker.goalPath.plans[id].{capacity,criterion,outcomes,versions}` — экспорт/импорт вместе с профилем.

## Отложено
- Полная карта функций по цели (пакеты работ, владельцы, брифы, приемка, CAP-11, 19, 21, 30, 32): нужен отдельный экран плана, крупное изменение интерфейса.
- Синтез до старта Реактора (CAP-23), учет психотипа, 13 направлений и почерка героя в подсказке: требует сверки источников.
