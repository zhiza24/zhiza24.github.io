# Сетка вау-моментов

Компонент `wow.js` → `GWow.show({...})`. Как появляется: затемнение, золотая вспышка, вращающиеся лучи, искры, затем карточка с одной ключевой мыслью и кнопкой «Беру с собой». Без библиотек. При `prefers-reduced-motion` анимации нет.
Правила:
- каждый момент показывается один раз (`P.self.wow[id]`) и сохраняется в дневник блоком `wow_<id>`, а в Герое — в «Нити Самости»;
- если нужных данных нет, момент не показывается, текст ничего не выдумывает;
- запуск — загрузка шага маршрута, следующего за источником данных (`self-thread.js`, функция run), через 0,7 с после открытия;
- в режиме просмотра (review) моменты не показываются.

Нарастание: опора → цифра твоего хорошего → связь из разных тестов → отложенная цитата → твои слова перед Стражем → встреча с прежним желанием → письмо.

## Как вызвать вручную (колесо, трекер)
```js
// Колесо (betraywheel.js / betray.html), после раскрытия надписей:
var sm = GBW.summary(P.betray.end || P.betray.start);
if (window.GWow && sm.sp.length) GWow.show({
  id: 'wheel_reveal',
  kicker: 'Колесо раскрылось',
  title: 'Сначала — твои опоры',
  text: sm.sp.slice(0,2).map(function(z){return z.s.m.t}).join(', '),
  sub: sm.sh.length ? 'И место, где ты чаще отступаешь от себя: ' + sm.sh[0].s.t.toLowerCase() + '.' : '',
  onClose: function(){ /* дальше выводы */ }
});
// Трекер, например день 21 или финал (тексты только из записей):
GWow.show({id:'tracker_d21', kicker:'21 день', title:'...', text:'...', quote:'«слова игрока»'});
```
`wow.js` подключается сам через `route.js` → `self-thread.js`. Если GWow нужен раньше, добавь `<script src="wow.js?v=self1"></script>`.

## Вход в трекер (tracker_open)
Трекер скрыт до итога Точки Б (`slot.html?id=pb_end`). Старые игроки с записями трекера видят его сразу.
После итога на ближайшей странице (pc_intro, arch_d, builder, tasks, hero, map, diary) один раз: «Твой путь на 28 дней открыт», кнопка «Открыть трекер» ведет в `reactor.html`.
Дальше вход: кнопка «Трекер» в Герое рядом с «Продолжить путь» и пункт «Трекер» в меню (до открытия пункт скрыт). Логика: `GSelf.trackerOpen()` в `self-thread.js`.
