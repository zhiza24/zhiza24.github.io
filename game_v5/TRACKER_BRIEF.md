# ТЗ: чистовой дизайн трекера «Реактор» (28 дней) для игры «Путь Алхимика»

Автор игры: Майя Явь. Нужен твой вариант схемы и макета трекера. Код игры не правь, пришли предложение.

## 1. Контекст
Мобильная веб-игра трансформации личности (PWA, чистый JS, без фреймворков). Игрок проходит маршрут: тесты, расшифровки, Самость, выбор желаний. Финальная часть — «Реактор»: 28-дневный трекер, где игрок живет обычные дни, делает маленькие шаги к своим желаниям и видит, как меняется. Сейчас трекер функционально богат, но «наляпан»: много вкладок, абзацев, цветов и кнопок. Нужно: интуитивно, чисто, минималистично, но чтобы вместило все ниже.

## 3. Что трекер должен вместить (все функции)
Ритм
1. Цикл 28 дней = 4 недели по логике «12 недель в году»: цикл = «год», неделя = «квартал». Недели с разной функцией: 1 настройка и наблюдение, 2 закономерности/переключение, 3 проверка в жизни, 4 закрепление и итоги.
2. Чистый печатный календарь месяца 4×7: в клетке только число и одна тихая отметка; сегодня подсвечено; слева номер недели 1–4.
3. Тап по дню разворачивает карточку дня, тап по номеру недели — вид недели. Повторный тап сворачивает.
4. Серия дней (число), тихий символ уровня пути (6 ступеней: Искра, След, Тропа, Путь, Русло, Круг).

День (главный экран использования, 1–3 минуты)
5. Подсказка внимания дня: одно предложение (28 разных текстов).
6. Задача дня / шаг стратегии: одно основное действие + минимальная версия («если нет сил») + альтернатива. Кнопка «Выполнить».
7. Цели/желания: главное заявленное желание и 3 направления (цели цикла); у направлений «если, то»; маленький шаг; чипы прогресса одним тапом («стало лучше», «привычка закрепляется», «вопрос решился»).
8. Состояние Героя (Sims): Энергия, Настроение, Самочувствие, Присутствие, Внутренняя опора — отметка 1–10 (на графиках 0–100). Подсказка только при низком значении. Ресурсы времени/внимания/действий/подтверждения намерений НЕ вводятся бегунками, а считаются из записей.
9. Записи дня по 8 сферам (для Зеркала): что делал, сколько времени, куда шло внимание (в делах / в мыслях), инициатива («сам» / «потому что надо»), эмоция, ощущение после, нереализованное желание. Должно быть быстрым (чипы, а не анкета).
10. Знаки дня (до 5 коротких записей) и «Мои доказательства».
11. Практики по выбору (свернуто): благодарности, «Выбираю — делаю — сделано», блоки времени, слова-тормоза, отметка самопредательства за день (сектор колеса), присутствие/тишина, новые привычки, аскеза, другие практики, заметка. Ориентир нагрузки: 1 основное действие + до 2 практик + 1 отметка состояния + 1 завершение дня. Практики включаются/паузятся/завершаются, серия считается по уникальным дням.
12. Режим дня по состоянию (мягкий диспетчер): восстановление / мягкий старт / рабочий / развитие / закрепление — по сочетанию показателей, пропуск не обнуляет прогресс.
13. Разбор дня: кнопка «Готово» внизу — короткий разбор по реальным отметкам и возврат к календарю. Данные сохраняются по ходу.
14. Самость: «Возвращение к себе в обычном дне» — короткий вопрос/напоминание дня, связь шагов с Самостью (сквозная нить игры). Утро: необязательный «Настрой дня», вечер: короткий итог.

Неделя
15. 3–4 числа (знаки, шаги, % плана, благодарности), график показателей недели (линии включаются легендой).
16. План недели 2–3 ключевых действия с отметками, 85% = успех.
17. Награда себе (назначает сам, дни 7, 14, 21), свернутый разбор недели (что сработало / помешало / беру дальше).
18. Сверка 21 дня: пауза-проверка перед финальной неделей.

Итоги и финал
19. Графики за 28 дней: энергия+настроение, самочувствие+присутствие, внутренняя опора; сравнение 1-й и 4-й недели; связи действий, нагрузки и состояния — без причинных выводов.
20. Зеркало прожитой жизни: исходное колесо 8 сфер (из начала игры) → наблюдение 28 дней → финальное колесо вслепую → три картины рядом: «как казалось», «как распределялись время и внимание по записям», «как видится теперь». Расхождение не называть самообманом; если данных мало — честно сказать.
21. Финал на 28-й день: «Было и стало», рецепт успеха по реальным отметкам, судьба желания (сбылось / приблизилось / отпущено), колесо самопредательства до/после, прогресс 3 направлений, награда, карточка-итог, начать новый цикл (пересобирается по результатам).
22. Настройки: только время мягкого напоминания (вход из итогов).

## 4. Проблемы текущего UX (по скриншотам)
- Три слоя навигации одновременно: верхняя панель + 4 вкладки (Мой день / Дневник / Мои направления / Практики) + нижнее меню; главная кнопка прячется за нижним меню.
- Заголовки длинные и наезжают на текст, много поясняющих абзацев.
- Пять показателей Sims — пять разных цветов, крупные полосы с вопросами на весь экран; ресурсы дня дублируют отметки.
- Колесо: подписи сфер обрезаны («Карьер»), два колеса мелкие, неясно, зачем смотреть.
- Одно и то же повторяется на месяце, в дне и в неделе; итоги разбросаны.

## 5. Стиль
Темный фон (почти черный теплый), золото и янтарь, один акцент. Шрифты: Cormorant Garamond (заголовки), Manrope (текст). Мобильный 375px, крупные зоны тапа, много воздуха. Ориентиры по ощущению: Kora, Вереск (спокойные трекеры-дневники). Одна главная золотая кнопка на экран, остальное — тихие ссылки и свернутые строки.

## 6. Ограничения
- Тексты только по-русски, без буквы «ё» (пиши «е»), обращение на «ты», формы по полу: {м|ж}.
- Не называть методики и авторов. Не обещать, что желание сбудется. Не ставить диагнозов.
- Каждая функция живет в одном месте, без дублей. Не перегружать день: все вторичное свернуто.
- Не терять сохранения: данные в localStorage, существующие поля и сырые ответы не переименовывать и не перезаписывать (можно добавлять новые).
- Без внешних библиотек.

## 7. Что прислать в ответ
1. Схему экранов и навигации: список экранов; на каждом — что видно сразу, что свернуто, откуда вход и куда выход; таблицу «функция → где живет» по всем 22 пунктам из раздела 3.
2. HTML-макет одним файлом (inline CSS/JS, без внешних библиотек, шрифты можно с Google Fonts), 375px, с демо-данными: месяц, открытый день, вид недели, итоги 28 дней с Зеркалом и графиками Sims. Кликабельно: тап по дню/неделе, сворачивание.
3. Короткий список: что из текущего трекера убрать, объединить или спрятать.
