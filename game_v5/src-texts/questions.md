Версия: 12.11.2026

## Общие правила

Шкала ответов для утверждений:

| Балл | Ответ              |
| ---- | ------------------ |
| 0    | Совсем не про меня |
| 1    | Скорее нет         |
| 2    | Иногда             |
| 3    | Скорее да          |
| 4    | Точно про меня     |
| —    | Не знаю            |

«Не знаю» не считается нулем и исключается из подсчета.

Обратные утверждения: балл пересчитывается по формуле `4 − ответ`.

Уровни:

| Итог  | Уровень                  |
| ----- | ------------------------ |
| 0–3   | Фоновая опора            |
| 4–7   | Эпизодическое проявление |
| 8–11  | Заметное влияние         |
| 12–16 | Выраженный автоматизм    |

Полнота результата:

- 4 ответа — полный результат.
- 3 ответа — среднее арифметическое трех ответов × 4, результат предварительный.
- Менее 3 ответов — недостаточно данных.

Важное техническое уточнение: в найденном исходном пакете 1 старые границы указаны как 0–2, 3–5, 6–8, 9–12. Здесь применяю границы 0–3, 4–7, 8–11, 12–16, которые ты задала в текущем техническом задании. Тексты уровней не переписываю.

Каждая шкала считается независимо. Обратные пункты пересчитываются по формуле `4 − ответ`. Затем складываются четыре значения.

Общий результат «ни одна из шести областей не выделилась как выраженная трудность» показывай, если все шесть шкал находятся в диапазоне 0–3.

Если две или более шкалы имеют одинаковый максимальный балл, показывай их вместе. Не выбирай ведущую шкалу по порядку ID.

### Правило подсчета

Обратные пункты пересчитываются по формуле `4 − ответ`. Максимум — 16 на шкалу.

Высокий балл означает развитую опору.

Результаты шести шкал самоотчета и ситуационного теста сохраняются отдельно. Их нельзя складывать в один общий балл.

## 4.2. Двенадцать учебных ситуаций

Все имена, числа, сообщения и обстоятельства в заданиях — вымышленные примеры.

В каждом задании нужно выбрать один наиболее обоснованный ответ.

### Ситуация 1. Отсутствие ответа

ID: CTSC01

Вымышленный пример: Лена написала коллеге утром. До вечера ответа нет. Какой вывод сейчас обоснован?

- A. Коллега намеренно игнорирует Лену.
- B. Ответа пока нет; причина неизвестна.
- C. Коллега больше не хочет общаться.

Ключ: B

| Вариант | Пояснение                                                                                                                              |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| A       | Такая версия быстро объясняет молчание и снимает неопределенность. Но намерение коллеги неизвестно: нет данных, видел ли он сообщение. |
| B       | Ответ фиксирует наблюдаемый факт и не приписывает причину. Он оставляет возможность проверить ситуацию.                                |
| C       | Категоричный вывод помогает быстро закрыть вопрос. Но одно отсутствие ответа не доказывает желание прекратить общение.                 |

### Ситуация 2. Жалобы покупателей

ID: CTSC02

Вымышленный пример: в магазине за неделю три покупателя пожаловались на новый чайник. Что лучше проверить перед выводом о всей партии?

- A. Сколько чайников продано и сколько было обращений по другим причинам.
- B. Считать всю партию бракованной.
- C. Решить, что покупатели неправильно пользуются чайником.

Ключ: A

| Вариант | Пояснение                                                                                                                        |
| ------- | -------------------------------------------------------------------------------------------------------------------------------- |
| A       | Сравнение количества продаж и обращений дает базу для оценки частоты проблемы. Без общего числа продаж нельзя оценить масштаб.   |
| B       | Обобщение по заметным случаям кажется осторожностью. Но оно игнорирует общее количество проданных товаров.                       |
| C       | Объяснение через ошибку покупателей защищает товар от поспешного обвинения. Но производственный дефект исключается без проверки. |

### Ситуация 3. Убедительная статистика

ID: CTSC03

Вымышленный пример: в публикации сказано, что «8 из 10 участников» улучшили результат. Что важно узнать?

- A. Только число лайков под публикацией.
- B. Только имя автора.
- C. Кто участвовал, как измеряли результат и где опубликованы данные.

Ключ: C

| Вариант | Пояснение                                                                                                           |
| ------- | ------------------------------------------------------------------------------------------------------------------- |
| A       | Популярность публикации легко принять за подтверждение. Но число лайков не показывает достоверность результата.     |
| B       | Авторство помогает установить происхождение сообщения. Но имени автора недостаточно для проверки методики и данных. |
| C       | Эти сведения позволяют оценить, что именно измеряли и насколько вывод поддержан доказательствами.                   |

### Ситуация 4. Обобщение по двум случаям

ID: CTSC04

Вымышленный пример: Игорь дважды опоздал на автобус и говорит: «Транспорт здесь всегда ходит плохо». Как точнее проверить вывод?

- A. Согласиться: двух случаев достаточно.
- B. Посмотреть расписание и данные о движении за более длительный период.
- C. Решить, что Игорь просто не умеет планировать.

Ключ: B

| Вариант | Пояснение                                                                                                                    |
| ------- | ---------------------------------------------------------------------------------------------------------------------------- |
| A       | Согласие с яркой формулировкой экономит время. Но два случая не показывают обычную работу транспорта.                        |
| B       | Расписание и более длинный период дают возможность проверить обобщение. Отдельные опоздания могут не отражать общую картину. |
| C       | Перенос причины на самого Игоря предлагает простое объяснение. Но данных о его действиях недостаточно.                       |

### Ситуация 5. Неподтвержденный срок

ID: CTSC05

Вымышленный пример: мастерская получила заказ, но поставщик еще не подтвердил срок доставки. Что разумнее сообщить клиенту?

- A. Назвать точную дату, чтобы клиент не волновался.
- B. Отказаться от заказа без уточнения.
- C. Сообщить, что срок пока не подтвержден, и назвать время следующего уточнения.

Ключ: C

| Вариант | Пояснение                                                                                                           |
| ------- | ------------------------------------------------------------------------------------------------------------------- |
| A       | Точная дата успокаивает клиента и делает ответ уверенным. Но неподтвержденный срок создает ложное ожидание.         |
| B       | Отказ снимает риск обещать неверный срок. Но заказ можно оценить после уточнения поставки.                          |
| C       | Ответ обозначает границу известного и дает следующий срок обновления. Он сохраняет контакт без выдуманной гарантии. |

### Ситуация 6. Новые данные

ID: CTSC06

Вымышленный пример: Мария считала, что доставка занимает два дня. Несколько последних заказов пришли за пять дней, и служба доставки опубликовала новое расписание. Что делать с прежним выводом?

- A. Обновить оценку с учетом новых данных и проверить, действует ли расписание сейчас.
- B. Продолжать считать, что доставка занимает два дня, потому что раньше так было.
- C. Решить, что служба доставки всегда нарушает сроки.

Ключ: A

| Вариант | Пояснение                                                                                                                                             |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| A       | Новые данные могут менять прежнюю оценку, если они надежны и относятся к текущей ситуации. Проверка актуальности помогает не делать лишних обобщений. |
| B       | Сохранение старого вывода поддерживает привычную картину. Но прежний опыт не отменяет новых сведений.                                                 |
| C       | Обобщение объясняет задержки одной причиной. Но оно не различает отдельные случаи и не доказывает постоянное нарушение сроков.                        |

### Ситуация 7. Неприветливый сосед

ID: CTSC07

Вымышленный пример: сосед не поздоровался утром. Какой вывод отделяет факт от догадки?

- A. Он сердится на тебя.
- B. Он не заметил тебя или был занят; причина пока неизвестна.
- C. Он специально показывает неуважение.

Ключ: B

| Вариант | Пояснение                                                                                         |
| ------- | ------------------------------------------------------------------------------------------------- |
| A       | Версия о раздражении быстро объясняет поведение соседа. Но его чувства не подтверждены фактами.   |
| B       | Ответ сохраняет факт и допускает несколько причин. Он не утверждает, что одна из них точно верна. |
| C       | Версия о неуважении делает ситуацию понятной. Но намеренное действие не подтверждено наблюдением. |

### Ситуация 8. Разные мнения специалистов

ID: CTSC08

Вымышленный пример: два специалиста по-разному объясняют поломку компьютера. Какой следующий шаг полезнее?

- A. Выбрать того, кто говорит увереннее.
- B. Считать, что оба ничего не понимают.
- C. Сравнить версии с наблюдаемыми признаками и проверить, какие данные различают их.

Ключ: C

| Вариант | Пояснение                                                                                                          |
| ------- | ------------------------------------------------------------------------------------------------------------------ |
| A       | Уверенный тон облегчает выбор. Но уверенность специалиста не показывает, какая версия лучше объясняет поломку.     |
| B       | Отказ от обеих версий избавляет от необходимости разбираться. Но противоречие не означает, что обе версии неверны. |
| C       | Проверка различающих признаков позволяет сравнить объяснения по фактам. Это точнее, чем выбирать по впечатлению.   |

ID: CTSC09

Вымышленный пример: блогер утверждает, что определенный прием помогает всем, но приводит только историю одного подписчика. Как оценить утверждение?

- A. История может быть примером, но сама по себе не доказывает общий эффект.
- B. Если история правдива, прием подходит всем.
- C. Большая аудитория блогера подтверждает утверждение.

Ключ: A

| Вариант | Пояснение                                                                                                                                       |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| A       | Единичная история может показать возможный случай, но не доказывает универсальный результат. Для общего утверждения нужны более широкие данные. |
| B       | Правдивый рассказ кажется сильным доказательством благодаря конкретности. Но один случай не показывает, что результат повторяется у всех.       |
| C       | Большая аудитория создает впечатление надежности. Популярность не заменяет проверку метода и данных.                                            |

ID: CTSC10

Вымышленный пример: человек замечает, что три знакомых сменили работу и стали довольнее. Он решает, что смена работы всегда делает людей счастливее. Что упущено?

- A. Ничего: три примера подтверждают правило.
- B. Нужно учитывать и другие случаи, причины перемен и тех, кому смена работы не помогла.
- C. Достаточно спросить еще одного знакомого.

Ключ: B

| Вариант | Пояснение                                                                                                                 |
| ------- | ------------------------------------------------------------------------------------------------------------------------- |
| A       | Несколько похожих историй создают убедительный образец. Но выборка мала и может не включать противоположные случаи.       |
| B       | Ответ учитывает выборочность наблюдений и возможные разные причины. Он не отрицает примеры, а ограничивает широту вывода. |
| C       | Дополнительный пример расширяет наблюдение. Но одного нового случая все еще недостаточно для правила «всегда».            |

### Ситуация 11. Решение при недостатке информации

ID: CTSC11

Вымышленный пример: для выбора курса не хватает отзывов выпускников, но регистрация закрывается завтра. Как поступить обоснованно?

- A. Выбрать наугад и не возвращаться к вопросу.
- B. Ждать полной информации, даже если срок пройдет.
- C. Отметить неизвестное, проверить доступные сведения и принять временное решение с понятным риском.

Ключ: C

| Вариант | Пояснение                                                                                                                |
| ------- | ------------------------------------------------------------------------------------------------------------------------ |
| A       | Случайный выбор позволяет не задерживаться на сложном решении. Но доступные сведения и риск остаются неучтенными.        |
| B       | Ожидание полной ясности кажется безопасным. Но оно игнорирует срок и возможность принять временное решение.              |
| C       | Ответ различает известное и неизвестное, использует доступные данные и признает риск. Решение остается пересматриваемым. |

### Ситуация 12. Пересмотр прежнего решения

ID: CTSC12

Вымышленный пример: Алексей уже купил дорогой прибор, но новые независимые проверки показывают, что он работает хуже заявленного. Что разумнее?

- A. Учесть новые данные и решить, можно ли вернуть прибор или изменить оценку покупки.
- B. Игнорировать проверки, чтобы не считать покупку ошибкой.
- C. Искать только отзывы, которые подтверждают прежний выбор.

Ключ: A

| Вариант | Пояснение                                                                                                                           |

| A       | Новые независимые проверки — основание пересмотреть прежнюю оценку. Практический следующий шаг помогает учесть последствия покупки. |
| B       | Игнорирование данных защищает от неприятного признания ошибки. Но цена покупки не опровергает новые проверки.                       |
| C       | Поиск подтверждающих отзывов сохраняет прежнюю позицию. Но выбор только удобных данных не позволяет оценить прибор объективно.      |

### Правило подсчета ситуационного теста

За верный ответ — 1 балл. За остальные ответы — 0 баллов.

Максимум — 12 баллов.

Распределение ключей:

- A — 4 правильных ответа.
- B — 4 правильных ответа.
- C — 4 правильных ответа.

Пояснения сохраняются для каждого варианта ответа. Они нужны для обратной связи, а не только для отображения правильного ответа.

1. Сравнивать каждую из четырех стратегий отдельно.
2. Если две стратегии имеют одинаковое максимальное среднее в настоящем, показывать обе.
3. Если стратегия изменилась, указывать, какая другая стратегия стала заметнее.
4. Не делать вывод о причине возникновения стратегии только на основании совпадения детских и нынешних ответов.
5. «Не помню» не означает, что стратегии не было.
6. «Не было» не означает, что стратегия была слабой.
