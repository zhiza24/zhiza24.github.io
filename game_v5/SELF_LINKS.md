# Нить Самости: что с чем связано

Модуль: `self-thread.js` (подключается сам из `route.js` на всех страницах маршрута). Вау-моменты: `wow.js`.

## Единый профиль выводов (без дублей)
Новое хранилище не заводилось. Выводы уже лежат в профиле `alch_v5_profile`:
- `P.diary.blocks[]` — итог каждого теста: `{id, step, title, lead, strong, insight, at, history}` (пишет `result-card.js`);
- `P.diary.ins[]` — слова игрока, его инсайты: `{x, d, at, blockId}`;
- поля модулей (`P.dialog`, `P.dq`, `P.desireLab`, `P.tracker.declared`, `P.betray`, `P.wheel`, `P.selfWorth`, `P.respTest`, `P.kmTest`, `P.ctTest`, `P.backgroundProfile`) и их история в `P.modules` (`profile-layer.js`).

`GSelf.insights(P)` собирает из них один список `{src, title, text, at, kind}`, где kind — это result / own / fact. Список только читает данные и ничего не копирует.
`GHeroSum.build(P)` (`hero-sum.js`) дает опоры, трудности и связи, подтвержденные двумя и более модулями.
Свое хранит только `P.self`: `voice{id: ts}` — прочитанные свитки, `wow{id: {at, title, text, page}}` — полученные озарения. Каждое озарение также пишется в дневник как блок `wow_<id>`.

## Тест → что фиксирует → где используется дальше
| Тест / шаг | Что фиксирует | Где используется |
|---|---|---|
| Кто сейчас выбирает (slot dialog) | `P.dialog` {self, ego} | вау «Первая опора» (bg16), GSelf.insights |
| Ведущее фоновое состояние (bg16) | `P.backgroundProfile`, блок дневника | итог Героя (GHeroSum), портрет, письмо Самости |
| Идеальный Кривой Мир (km) | `P.kmTest` | связи в GHeroSum → вау «Твой первый портрет» |
| Колесо самопредательства и опоры (betray) | `P.betray.start/end` | GHeroSum (опоры, где теряешь себя), свиток «Момент, когда я отступаю от себя», трекер (сектор дня), «Было и стало» |
| Свайп хорошего (swipe) | `P.dq` {accepted, voices, answers}, блок `good_swipe` | вау «Сначала опора» (res.html) |
| Ресурсы и тело (res) | блок `resources_body` | Герой: глава, дневник |
| Мой первый портрет (fin) | блок `first_portrait` | вау «Твой первый портрет» + свиток «Часть I пройдена» |
| Колесо баланса (wheel8) | `P.wheel` (8 сфер) | GHeroSum (сфера-опора / просит внимания), письмо Самости, Зеркало прожитой жизни |
| Фактическая картина жизни (wheel-test) | `P.wheelTest`, блок `wheel_test` | Зеркало прожитой жизни в трекере |
| Карта ценностей (values) | `P.values`, блоки `values_*` | Три ориентира, трекер |
| Самоценность / Ответственность / Критическое мышление (sv, rs, ct) | `P.selfWorth`, `P.respTest`, `P.ctTest` | GHeroSum: опоры, трудности и связи → портрет, письмо |
| Лабиринт желаний (lab_d) | `P.desireLab.desire` | вау «Запомни эти слова» (wish), «Что ты писал{|а} в начале» (wish_back), письмо Самости |
| Небо желаний (wish) | `P.tracker.declared`, направления | вау «Что ты писал{|а} в начале», письмо Самости, трекер |
| Инсайты игрока (Герой, итоги) | `P.diary.ins` | вау «Твои слова» (Страж), письмо Самости |
| Трекер 28 дней | `P.tracker` | ежедневный вопрос `GSelf.dailyQuestion()`, свиток «Возвращение к себе в обычном дне» |

## Свитки «Голос Самости»
Тексты взяты из материала Самости и переведены в формы {м|ж}. Каждый свиток при первом заходе открывается сам, потом остается значком в шапке. Все прочитанные свитки можно перечитать в Герое, в блоке «Нить Самости».
| Точка | Свиток | Как показывается |
|---|---|---|
| hero.html (Герой) | 01 «Здесь начинается знакомство» | при первом открытии |
| slot.html?id=dialog | 02 «Я есть» | сразу после заставки «Я есмь», до «Кто сейчас выбирает» |
| betray.html | 04 «Момент, когда я отступаю от себя» | через 3,5 с после того, как колесо пройдено (`P.betray.done`). Отключить: `window.GSelfNoAuto=true` и вызвать `GSelf.voice('wheel')` самому |
| fin.html (Мой первый портрет) | «Часть I пройдена» + ссылка в лабораторию | после вау «Твой первый портрет» |
| slot.html?id=arch_p и guard (Страж) | 06 «На чьей я стороне?» | первый из двух шагов |
| Трекер | 12 «Возвращение к себе в обычном дне» | не подключен автоматически: в трекере вызвать `GSelf.voice('tracker')` при входе, а в записи дня — поле с `GSelf.dailyQuestion()` |
| slot.html?id=end (финал) | 13 «Не нужно становиться другим» | после письма Самости |
